# Security policy

## Supported versions

This project is experimental. Security fixes are applied to the latest code on
`main`; older commits and forks do not receive separate security updates.

## Report a vulnerability

Email Mahmood Khordoo privately at
[m.khordoo@gmail.com](mailto:m.khordoo@gmail.com) with the subject
`Jev Reflex Autonomy Lab security report`.

Include the affected commit, a description of the issue and potential impact,
and minimal steps to reproduce it. Redact API keys, personal data, and other
secrets. Please do not open a public issue or pull request containing exploit
details before a fix can be coordinated.

The maintainer will review the report and coordinate next steps by email.
There is no guaranteed response or fix timeline. Please allow time for an
investigation before publishing details.

## Scope

Reports about exposed provider credentials, server request handling, dependency
vulnerabilities affecting this app, and other project security issues are welcome.
For vulnerabilities in TypeSafe, OpenRouter, or another external service, use
that service's own reporting process.

Test only systems and accounts you are authorized to use. If a credential has
been exposed, revoke or rotate it with the provider immediately.
